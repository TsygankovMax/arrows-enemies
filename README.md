# Лабиринт стрелок: варианты врагов

Страница сравнения: [посмотреть](https://tsygankovmax.github.io/arrows-enemies/)

Три подхода к замене врагов рядом с тем, что стоит в игре сейчас. Всё живое:
переключаются состояние (ожидание, ходьба, стрельба, смерть) и размер.

| колонка | что это |
|---|---|
| сейчас | шесть картинок художницы на десять типов, статика |
| C | схема из демки Daniil'а: голова + торс + оружие, шарнир, отдача, вспышка |
| D | та же механика без оружия: голова + корпус |
| генератор | картинка от нейросети, фон вырезан, движение тем же кодом |

## С чего смотреть

Ставьте размер **«как в игре · 21 px»**. Это не условность: монстр в игре
занимает 2.02 клетки, а клетка на телефоне по медиане всех 430 позиций —
10.3 css px. На этом размере не работают ни оружие, ни вспышка, ни мелкие
детали; работают силуэт, цвет и движение. Крупные размеры — только чтобы
разглядеть.

## Что здесь измерено, а что придумано

Из данных игры взяты только мировой размер врага (2.222 из `SkeletonDataAsset.scale`)
и якорь по земле — сдвинуть их нельзя, иначе поедет измеренная плотность очереди
на кольце.

Силуэты, цвета, тайминги анимации и промпты генератора — придуманы: ни кадра
оригинала с этими врагами, ни образца от художника нет.

## Чего страница не решает

Нынешние враги — работа художницы студии. Их замена это решение людей, а не кода.
Здесь показано только, чем можно заменить и как это выглядит на настоящем размере.
